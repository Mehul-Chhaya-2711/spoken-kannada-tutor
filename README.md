# Spoken Kannada Tutor Agent

A simple beginner-friendly AI-style tutor app for learning spoken Kannada through English transliteration.

## Live App
[Try the app here](https://spoken-kannada-tutor.streamlit.app/)

## What it does
- Teaches beginner-level spoken Kannada
- Uses English transliteration only
- Shows one lesson at a time
- Gives one homework exercise per lesson
- Evaluates the learner's answer
- Gives a better version and English meaning
- Allows progress only after passing the current lesson

## Version 1 Features
- Text-only app
- 5 beginner lessons
- Friendly pass/retry logic
- Simple progress tracking
- Built with Streamlit

## Example inputs
- `namaskara`
- `nanage neeru beku`
- `idu nanna mane`
- `nanu barthini`
- `dayavittu matte heli`

This is the first simple MVP of a Spoken Kannada Tutor Agent. Future versions may include smarter evaluation, more lessons, and speech support.
